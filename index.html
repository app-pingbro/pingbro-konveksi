Preview Tautan

Kartu yang muncul saat link situs dibagikan ke WhatsApp, Telegram, atau Facebook

Konveksi & Sablon Aplikasi Manajemen Operasional, Produksi & Keuangan alamat-situs-anda
Aplikasi pembaca tautan (WhatsApp, Facebook, Telegram) tidak menjalankan JavaScript, jadi kartu preview harus berupa teks statis di index.html dan berkas gambar di folder situs. Dua hal yang perlu Anda lakukan:

1. Sekali saja — tekan Salin Baris Meta, buka index.html, lalu ganti empat baris bertanda ⤵ dengan hasil salinan itu. Alamat situsnya sudah terisi otomatis dari alamat halaman ini.
2. Setiap ganti Logo Perusahaan — tekan Buat Ulang logo-share.png, timpa berkasnya di folder proyek, lalu git add . && git commit -m "logo baru" && git push.

WhatsApp menyimpan preview per tautan cukup lama. Untuk menguji hasilnya, kirim tautan dengan tambahan ?v=2 di belakangnya.

Bantuan

Alur kerja aplikasi dari order sampai pelunasan

Alur Kerja Utama

  1. Buat Order — tekan tombol di tengah dock, isi customer, item, dan DP.
  2. SPK Otomatis Terbit — setiap order langsung menghasilkan nomor SPK untuk workshop.
  3. Update Status Produksi — ubah SPK: Belum Dikerjakan → Proses → Selesai.
  4. Pantau Deadline — order lewat tanggal dan belum selesai otomatis ditandai Terlambat.
  5. Cetak Invoice — invoice dibuat sebagai gambar JPG siap dikirim atau dicetak.
  6. Catat Pelunasan — status pembayaran berubah otomatis: Belum Bayar → DP → Lunas.

Pertanyaan Umum

Kenapa gambar SPK / Invoice tidak muncul?

Dokumen dibuat langsung di browser sebagai JPG. Bila gagal, tunggu sampai proses selesai (dokumen padat butuh beberapa detik) lalu coba lagi. Pastikan juga setupAppEnvironment() sudah dijalankan dan izin Drive sudah disetujui agar mockup bisa terbaca.

Data tidak berubah setelah edit di Spreadsheet?

Tekan tombol di header untuk memuat ulang data dari server.

Harga tidak terisi otomatis?

Lengkapi kombinasi Jenis Produk × Kategori × Ukuran pada menu Master Harga.

Cara menulis rumus

Variabel yang tersedia

  • COWOK · CEWEK · ANAK — jumlah pcs kategori tersebut
  • COWOK XS-M — dibatasi rentang ukuran
  • COWOK M — satu ukuran saja
  • TOTAL — semua pcs yang lolos penyaring di atas
  • TOTAL SEMUA — semua pcs pada order, tanpa penyaring
  • PRODUK Lengan Panjang — pcs jenis produk tertentu

Operator + - * × / dan tanda kurung ( ). Desimal boleh pakai koma: 5,5

Contoh
(COWOK XS-M / 6) + (COWOK L-XL / 5,5) + (CEWEK XS-XXXL / 6)
TOTAL / 4 × 13

Ukuran buatan sendiri (mis. "4L Jumbo") ikut terhitung pada TOTAL dan rentang penuh XS-XXXL, tetapi tidak pada rentang sempit seperti L-XL.
